Работа Перегудова Романа

Условие задачи:

Напишите программу перевода чисел от 1 до 13 в слова

Алгоритм решения задачи

Начало.

Ввести число num.

Проверить значение числа:

Если num = 1, вывести «Один».

Если num = 2, вывести «Два».

Если num = 3, вывести «Три».

Если num = 4, вывести «Четыре».

Если num = 5, вывести «Пять».

Если num = 6, вывести «Шесть».

Если num = 7, вывести «Семь».

Если num = 8, вывести «Восемь».

Если num = 9, вывести «Девять».

Если num = 10, вывести «Десять».

Если num = 11, вывести «Одиннадцать».

Если num = 12, вывести «Двенадцать».

Если num = 13, вывести «Тринадцать».

Если число не входит в диапазон от 1 до 13, вывести сообщение «Число вне диапазона 1–13».

Конец.
